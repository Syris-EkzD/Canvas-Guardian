# Canvas Guardian v0.3.1

Canvas Guardian v0.3.1 is a focused maintenance release for correctness, privacy, and Google Calendar recovery. It preserves the v0.3.0 feature set while fixing edge cases found during the post-release engineering audit.

## Correctness fixes

- Graded Canvas submissions remain unfinished when Canvas explicitly marks them as missing and there is no affirmative submission evidence.
- Explicit submission timestamps, submitted workflow state, and legitimate non-missing graded work still count as submitted.
- The standalone announcement monitor safely returns no announcements when there are no active courses.
- Legacy diagnostic scripts now use complete paginated Canvas reads.

## Privacy fix

Malformed attendance CSV parser failures are sanitized before they reach terminal or log output. Errors may include safe parser codes or numeric position information, but never raw parser messages, record contents, student values, or arbitrary malformed field text.

## Calendar reliability

- Reconciliation now starts from the complete successfully fetched Canvas assignment snapshot rather than filtering away information needed to clean up stale mappings.
- Existing Guardian-managed events are removed when assignments disappear, become unpublished, lose their due date, or become submitted.
- Remote deletion responses 404 and 410 both confirm that the event is already gone; other deletion failures retain the local mapping and propagate.
- Update recovery treats 404 and 410 consistently.
- Unmapped assignments first look for an exact Guardian-managed event in the configured destination calendar using the existing private assignment metadata. A single matching event is recovered instead of duplicated; multiple matches fail explicitly.
- Replacement inserts must return a usable Google event ID before a mapping is saved.
- Existing unchanged-event behavior and old unsynced past-due skipping remain intact.

## Testing improvements

The deterministic suite now includes focused regression coverage for missing-submission semantics, attendance parser privacy, Calendar reconciliation and recovery paths, duplicate-prevention after ambiguous creation, Google 404/410 handling, and zero-active-course announcements.

The `better-sqlite3` runtime dependency was updated from the 11.x native-addon line to the N-API-based 13.0.3 line for reliable Node 24 compatibility.

## Upgrade note

No environment variables changed. Update to the v0.3.1 source, run `npm ci`, and keep the existing private `.env`, Google OAuth files, and local runtime state as before.
